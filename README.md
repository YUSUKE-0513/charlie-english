# Charlie English（小学2年生向け 英語フレーズ学習アプリ）

ブラウザだけで動く静的Webアプリです。Claudeへのログイン・サーバー・外部API・外部フォントは使いません。
学習記録は **その端末のブラウザ内（localStorage）だけ** に保存され、どこにも送信されません。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 入口 |
| `styles.css` | 見た目 |
| `phrases.js` | **フレーズデータ（52個）**。学習記録とは別ファイル |
| `app.js` | Daily Cards・瞬間英作文・保存・音声のロジック |
| `data.js` | 記録の書き出し／読み込み（JSON） |
| `manifest.json`, `icons/` | ホーム画面に追加するための設定とアイコン |
| `sw.js` | オフライン用キャッシュ（ネット優先） |

ビルドは不要です。すべて相対パスなので、`https://ユーザー名.github.io/リポジトリ名/` のようなサブフォルダ配下でも動きます。

## 1. GitHub Pages で公開する（あなたが行う操作）
1. https://github.com にログイン →右上「＋」→ **New repository**。
2. Repository name（例 `charlie-english`）を入れ、**Public** を選び、**Create repository**。
   - Pages（無料）は Public が基本です。**記録（個人情報）はリポジトリに入れません**（記録は端末内のみ）。
3. 作成後の画面で **uploading an existing file** をクリック。
4. このフォルダの中身（`index.html` など、`icons` フォルダも）を**まとめてドラッグ**。ZIPのまま上げず、解凍してから上げてください。
5. 下の **Commit changes** を押す。
6. リポジトリの **Settings → Pages** を開く。
7. **Build and deployment → Source: Deploy from a branch**、**Branch: `main` / `/ (root)`** を選んで **Save**。
8. 1〜3分待って同じ画面を更新すると、上部に公開URL（`https://ユーザー名.github.io/charlie-english/`）が出ます。これが専用URLです。

### 更新するとき
- フレーズを足す・直すとき：リポジトリで該当ファイルを開き ✏️(Edit) → Commit changes。数分で反映されます。
- **`phrases.js` は各リストの「最後」にだけ追加してください**（IDは並び順で決まるため、途中に挿入・並べ替えると学習記録がずれます）。

## 2. iPad で使う
1. iPad の **Safari** で公開URLを開く。
2. 共有ボタン（□↑）→ **ホーム画面に追加** → 追加。
3. 以降はホーム画面のアイコンから起動できます（Safariのバーなしで表示）。

### 大事な注意（記録が消えないように）
- iPadのSafariは、**しばらく使わないサイトのデータを消すことがあります**（ホーム画面に追加したアプリはこの制限を受けにくいですが、保証はありません）。
- 「Safariの履歴とWebサイトデータを消去」をすると**記録も消えます**。
- 週に一度ほど、下の方法で**書き出して保存**しておくと安心です。

## 3. 記録の書き出し・読み込み
ホーム →「💾 きろくの ほぞん・よみこみ」
- **書き出す**：「ファイルに ほぞん」（.jsonが保存されます。うまくいかなければ「もじを コピー」）。
- **読み込む**：ファイル選択、または貼り付け →「チェックする」→ 内容確認 →
  - 「あわせる」：今の記録を残しつつ、新しい方を採用（基本はこちら）
  - 「ぜんぶ おきかえる」：確認ダイアログのあとに置き換え
- 形式チェックに通らないファイルは読み込まれません。読み込み直前に、今の記録を端末内にバックアップ（`charlie-english-v1-backup`）します。

### 旧Claude版からの移行
旧Artifactは別の保存領域のため、**自動では引き継がれません**。
1. 旧アプリのホームで「📤 きろくを あたらしい アプリに うつす」→「コピー」。
2. 新アプリの読み込み欄に貼り付け →「チェックする」→「あわせる」。
※ 旧版を同じiPadで使っていない／記録がほぼ無い場合は不要です。

## 4. 音声が動かないとき
- **発音が出ない**：iPadのマナーモード（消音）を解除し、音量を上げる。ボタンを押したときにだけ再生されます。
- **マイクが使えない**：設定 → Safari → マイク を「確認」または「許可」。Siri と音声入力（設定 → 一般 → キーボード → 音声入力）がオフだと、音声認識が使えないことがあります。
- 認識に通信が必要な場合があります。ネットにつながっているか確認してください。
- それでも使えないときは、画面の「かいて こたえる」で入力して進められます。

## 5. しくみと限界
- 瞬間英作文の判定は、大文字小文字・句読点・短縮形（I'm=I am など）をそろえて模範解答と比べ、指定フレーズが使われているかも見ます。
- 模範解答にない自然な別解は、自動では正しく判定できません。そのため「判定保留」と、不正解のあとの「じぶんの こたえも あってた」を用意しています。
- 発音は精密に評価していません（音声認識の結果で聞き取れなかった語を示すだけです）。

## 6. 使っている外部ライブラリ
なし（HTML / CSS / JavaScript のみ。外部の通信先もありません）。
